## Маршрутизация запросов

**Первый контакт — всегда через скилл `agent-router`** (`.claude/skills/agent-router/`,
вызывается через `Skill`, не через `Agent` — это не отдельный субагент, а моя
собственная процедура классификации). Классифицирую запрос (тип/сложность/
критичность) сама и решаю, кому его передать: простые/средние задачи —
напрямую исполнителю через `Agent`, сложные многошаговые — сначала через скилл
`task-coordinator` (`.claude/skills/task-coordinator/`) на декомпозицию в
атомарные task-карточки (кому, зачем, вход/выход, требования, ограничения,
критерии успеха, зависимости). Тривиальный однозначный запрос в один шаг можно
направить исполнителю напрямую, без формального прогона через скиллы.

Оба скилла — `disable-model-invocation: true`: это правило и есть их триггер,
а не автосрабатывание по описанию (не задваивает контекстную нагрузку).

Типовой конвейер: **research → build → verify**.

## Агенты (subagents в `.claude/agents/`)

Ростер изначально перенесён из общего репозитория агентов (`LecksLecks/Slom`);
трейдинг-агенты, которые этому репо не были нужны по сути, удалены по явному
запросу пользователя.

### Инженерия и качество
- **code-craftsman** — производственный код высокого качества; сам не коммитит.
- **bug-diagnostician** — систематическая диагностика трудных багов и регрессий (петля → репродукция → гипотезы → фикс+регрессионный тест); сам не коммитит.
- **work-verifier** — независимый read-only аудит готовой работы (вердикт PASS/FAIL).
- **prompt-engineer** — проектирование/улучшение промптов, агентов, скиллов.
- **token-optimizer** — сжимает раздутый текст/ответ на 30–50% без потери сути (read-only рефакторинг).
- **agent-factory** — если для запроса нет подходящего агента, сама проектирует новый (или цепочку), пишет файл в `.claude/agents/`, регистрирует в этом ростере и сразу запускает на задаче в этом же ходе; сначала всегда проверяет, не дублирует ли уже существующего агента.

### Threads / Instagram (Metricool, публикация только черновиком)

Многоступенчатая специализация: точка входа — `instagram-agent-supervisor`
(роутер + независимая верификация результата по чек-листу; вызывать напрямую
специалистов тоже можно для точечной задачи). Единственный агент с правом
записи в календарь Metricool — `smm-instagram-manager`, все остальные —
read-only или отдают готовый материал ему на постановку в черновик.

- **instagram-agent-supervisor** — точка входа для IG/Threads/n8n-задач: бриф → диспатч специалисту(ам) → верификация результата → отчёт.
- **ig-content-strategist** — контент-стратегия на месяц + трендресёрч/конкуренты (Instagram), read-only.
- **ig-trend-scout** — реал-тайм скан вирусных форматов/тем (окно часы-дни, не месяц); отдельно от ig-content-strategist по кадансу.
- **ig-creative-director** — визуальные концепции постов и сценарии/монтажные листы рилов (бриф, не рендер).
- **instagram-producer** — покадровый сценарий + план съёмки по уже одобренной концепции (после ig-creative-director).
- **ig-copywriter** — тексты постов/рилов Instagram в голосе аккаунта.
- **ig-compliance-checker** — проверка готового контента на риски перед публикацией (вердикт PASS/FLAG).
- **ig-performance-analyst** — отчёты по метрикам аккаунта (Instagram/Threads/TikTok), read-only.
- **instagram-competitor-analyst** — регулярный конкурентный бенчмаркинг Instagram (рост/вовлечённость/что заходит у конкурентов), read-only.
- **smm-instagram-manager** — единственный агент с записью в Metricool; берёт готовый текст+медиа и ставит черновик (draft всегда true, без исключений).
- **threads-content-strategist** — стратегия Threads: пилларсы, каденс, микс постов/тредов, квота реплаев.
- **threads-copywriter** — тексты постов и цепочек постов Threads.
- **threads-engagement-manager** — реплай-стратегия и черновики ответов на конкретные Threads-переписки (без доступа к живой ленте).

### Монтаж видео (ffmpeg, локальные файлы)

Пайплайн после съёмки: сборка → отделка (цвет/звук/субтитры) → проверка
удержания → спек-QC и экспорт. Ни у одного из этих агентов нет записи в
Metricool: отдают файл пользователю, публикация — только через
`smm-instagram-manager` (и ему нужен публичный URL, у локального файла его нет).
Порядок: `ig-creative-director` (бриф/монтажный лист) → `instagram-producer`
(съёмка) → **reels-editor** → **reels-colorist** + **reels-sound-designer** +
**reels-caption-artist** → **reels-retention-doctor** (правки возвращаются в
reels-editor) → **reels-delivery-qc** → пользователь.

- **reels-editor** — сборка рила из сырых клипов через ffmpeg по готовому брифу: обрезка, склейка, кроп 9:16, переходы; отделку отдаёт профильным соседям.
- **reels-caption-artist** — субтитры и кинетический текст: тайминг, разбивка, `.srt`/`.ass`, стиль, safe zone, вжигание; ASR в среде нет — работает от готовой расшифровки.
- **reels-colorist** — цветокоррекция и единый look: выравнивание экспозиции/ББ между клипами, LUT, устойчивость к сжатию Instagram.
- **reels-sound-designer** — звук: нормализация до −14 LUFS, дакинг музыки под речь, чистка речи, SFX, бит-сетка под склейки.
- **reels-retention-doctor** — разбор готовой сборки на удержание (хук 0-3 с, темп, мёртвые зоны, петля) → список правок с таймкодами; сам не монтирует.
- **reels-delivery-qc** — финальный технический QC + экспорт под спеку IG (9:16, fps, битрейт, yuv420p, LUFS, faststart) и cover-кадр; вердикт PASS/FAIL.

### Прочее
- **n8n-agent-builder** — проектирует/валидирует/деплоит n8n-автоматизации (постинг, отчёты, алерты) поверх Metricool/Windsor.ai/Supermetrics.
- **web-researcher** — глубокое чтение источников через WebFetch (не только сниппеты), фактчекинг, разбор конкурентных аккаунтов вне метрик Metricool.
- **web-search** — поиск актуальных/внешних фактов с цитированием (read-only).

### Экономия токенов — обязательна для всех агентов

Каждый агент в `.claude/agents/` держит раздел «Экономия токенов» / «Token economy»:
без вводных фраз, без повторов, без очевидного, таблицы вместо прозы, примеры по
требованию — но **обязательный формат вывода агента не режется**, экономится только
проза вокруг него. **Новый агент обязан включать этот раздел** (см. формулировку в
любом существующем агенте как образец). Для сжатия уже готового текста/ответа —
`token-optimizer`.
